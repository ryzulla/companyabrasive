## Ringkasan website

Website ini terdiri dari dua bagian:

**Website publik** (dilihat pengunjung)

- Beranda dengan hero, kategori, katalog produk, video, E-Catalog, klien, testimoni, FAQ, blog, dan formulir kontak
- Katalog produk dengan pencarian, filter kategori, dan detail produk berfoto banyak
- Blog dengan alamat tersendiri untuk tiap artikel
- Halaman Tentang Kami (profil, visi dan misi)
- Formulir testimoni privat lewat link sekali pakai
- Dua desain yang dipilih otomatis: desktop dan mobile

**Panel Admin** (dikelola pemilik)

- Kelola produk, kategori, artikel, video, FAQ, testimoni, dan klien tanpa menyentuh kode
- Pesan masuk dari formulir kontak, dengan balasan lewat email atau WhatsApp
- Pengaturan teks, tampilan, kontak, SEO, dan media sosial
- Dua peran pengguna: Superuser dan Admin

## Mulai cepat untuk pengelola konten

1. Masuk di `/login` ([caranya](01-panduan-admin.md#11-masuk-ke-panel-admin)).
2. Ganti password awal ([caranya](01-panduan-admin.md#114-akun-saya)).
3. Lengkapi **Pengaturan** (identitas, kontak, nomor WhatsApp, foto hero dan Tentang) ([caranya](01-panduan-admin.md#113-pengaturan-website)).
4. Tambahkan **Produk** dan **Artikel**.
5. Kirim **link testimoni** ke klien yang puas ([caranya](01-panduan-admin.md#18-testimoni-dan-link-testimoni-untuk-klien)).

## Tentang gambar di dokumentasi

Semua gambar ada di folder `images/`. Tangkapan layar diambil dari website yang berjalan dengan data contoh, jadi isi produk, pesan masuk, dan pengaturan pada gambar mungkin berbeda dengan data asli Anda. Alamat `127.0.0.1` pada beberapa gambar hanyalah alamat komputer lokal. Di website sebenarnya alamat itu diganti domain Anda.
